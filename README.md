# Anki Maker
Anki maker is a frontend-only website that helps you create Anki cards from prompts using GPT and OpenAI TTS.

### Demo

[![Demo Video]()](https://youtu.be/qz1la5ZFIRM)

## Features
- ✨ AI-powered card generation using OpenAI GPT
- 🔊 Audio generation using OpenAI TTS API
- 🎯 Integration with Anki desktop via AnkiConnect
- 📱 Browser bookmarklet for quick text selection
- 🎨 Modern Material-UI interface

## Development

```bash
pnpm dev     # Start development server
pnpm build   # Build for production
pnpm test    # Run tests
```

## Setup
1. Install Anki desktop + AnkiConnect plugin
2. Add your OpenAI API key in Settings (used for both GPT and TTS)
3. Start creating cards!
